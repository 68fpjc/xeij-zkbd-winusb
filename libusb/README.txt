This directory contains unmodified libusb-1.0.dll binaries (libusb 1.0.29)
used by the Z keyboard WinUSB support (ZKeyUsbPort).

  windows-amd64   : VS2022\MS64\dll\libusb-1.0.dll
  windows-aarch64 : MinGW-llvm-aarch64\dll\libusb-1.0.dll
